# ChronosMatch
Zero-Copy High-Frequency Trading Engine | Python Development Internship | Group 10
## Order Book Management and Order Matching

### Overview
This module manages buy and sell orders and supports order matching in the ChronosMatch trading engine.

### Features
- Buy order management
- Sell order management
- Price-based order matching
- Partial order fill handling
- Unit testing for order book functionality

### Project Files
- `order_book.py` – Implements the order book.
- `add_buy_order.py` – Manages buy orders.
- `sell_order.py` – Manages sell orders.
- `order_matching.py` – Implements order matching.
- `partial_fills.py` – Handles partial order fills.
- `test_order_book.py` – Contains order book test cases.

### Running Tests
Run the following command from the project root directory:

```bash
python -m unittest discover -v
```
