Project scope

A working educational simulator. The downloaded edition runs the Python engine behind this interface. The hosted demo runs a separate JavaScript matcher and stores its state in this browser.

Zero-copy objective. Binary parsing avoids payload slices. Decoding, Python order objects, JSON and database writes still allocate memory. This is not an end-to-end zero-copy system.

Execution boundary. Simulated liquidity and simulated executions. Exchange connectivity, brokerage accounts, real-time market feeds and production HFT guarantees are outside this edition.
